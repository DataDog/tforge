# Security Policy

Datadog takes the security of this project seriously. If you believe you have
found a security vulnerability, please **do not** open a public GitHub issue.

## Reporting a vulnerability

Report suspected vulnerabilities through Datadog's HackerOne bug bounty
program: https://hackerone.com/datadog

Alternatively, email security@datadoghq.com with details of the issue. See
https://www.datadoghq.com/security/ for more on Datadog's security program.

## Supported versions

tforge is pre-1.0 and evolving rapidly. Security fixes are made against the
latest released version; older versions are not separately patched.
